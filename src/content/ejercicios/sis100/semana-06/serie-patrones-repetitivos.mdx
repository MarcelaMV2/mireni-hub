## Enunciado

Desarrolla un programa que permita generar una serie numérica con un patrón repetitivo. El usuario debe ingresar la cantidad de términos **`N`** que desea mostrar.

La serie se genera de la siguiente manera:

```text
+5   -8   +10   -16   +15   -24   +20   -32   +25   -40 ...
```

Además de mostrar los términos, el programa debe calcular la suma de toda la serie. El dato `N` debe validarse: solo se aceptan valores positivos; no se admiten cero ni números negativos. Para generar la serie se debe usar la estructura repetitiva **`Para`**.

## Datos de entrada y salida

- **Entrada:** `n`, cantidad de términos que se desean generar. Debe ser un entero mayor que cero.
- **Salida:** los `n` términos de la serie y la suma total de esos términos.

## Análisis del patrón

La serie alterna dos subseries:

| Posiciones | Términos | Regla |
| --- | --- | --- |
| Impares: `1, 3, 5, ...` | `+5, +10, +15, ...` | aumenta de `5` en `5` |
| Pares: `2, 4, 6, ...` | `-8, -16, -24, ...` | disminuye de `8` en `8` |

El contador `i` recorre las posiciones desde `1` hasta `n`. Si `i` es impar, se incrementa el contador `pos` y el término es `pos * 5`. Si `i` es par, se incrementa el contador `neg` y el término es `neg * -8`.

Por ejemplo, para `n = 6` se obtiene `5, -8, 10, -16, 15, -24`; la suma es `-18`.

## Validación de `n`

Antes de usar `Para`, se lee `n` y se vuelve a solicitar mientras `n <= 0`. Así se rechazan valores negativos y el cero. Cuando `n` es positivo, `Para i <- 1 Hasta n` garantiza exactamente `n` vueltas.

<Codigo archivo="serie_patrones_repetitivos.cpp" lang="cpp" codigo={`#include <iostream>
using namespace std;

int main() {
    long long n, pos, neg, termino, suma;

    cout << "Ingrese la cantidad de terminos: ";
    cin >> n;
    while (n <= 0) {
        cout << "Error. La cantidad debe ser positiva: ";
        cin >> n;
    }

    pos = 0;
    neg = 0;
    suma = 0;
    cout << "Serie:" << endl;
    for (long long i = 1; i <= n; i++) {
        if (i % 2 == 1) {
            pos = pos + 1;
            termino = pos * 5;
        } else {
            neg = neg + 1;
            termino = neg * -8;
        }
        cout << termino << " ";
        suma = suma + termino;
    }

    cout << endl;
    cout << "Suma total: " << suma << endl;
    return 0;
}`} />

En PSeInt, `MOD` permite saber si una posición es par o impar. En C++, esa misma operación se escribe con `%`. La estructura `Para` se traduce a `for`: inicializa `i` en `1`, repite mientras `i <= n` e incrementa `i` al finalizar cada vuelta.
