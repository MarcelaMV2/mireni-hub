El programa selecciona **una figura**, solicita sus medidas y calcula el área y el perímetro si los datos son positivos. Cada figura tiene su propio caso y sus propias validaciones.

## Datos de entrada

| Variable | Tipo en PSeInt | Significado | Validación y uso |
| --- | --- | --- | --- |
| `opcion` | Entero | Figura elegida: `1` cuadrado, `2` rectángulo, `3` triángulo, `4` círculo. | `Segun` selecciona el caso. Otros valores llegan a `De Otro Modo`. |
| `lado` | Real | Longitud de un lado del cuadrado. | `lado > 0`, solo en el caso `1`. |
| `base` | Real | Base del rectángulo o del triángulo. | `base > 0`, en los casos `2` y `3`. |
| `altura` | Real | Altura del rectángulo o altura perpendicular a la base del triángulo. | `altura > 0`, en los casos `2` y `3`. |
| `lado1`, `lado2`, `lado3` | Real | Longitudes de los tres lados del triángulo. | Cada lado debe ser mayor que cero, en el caso `3`. |
| `radio` | Real | Distancia del centro del círculo a su borde. | `radio > 0`, solo en el caso `4`. |

Las medidas son reales porque admiten decimales, como `2.5`. Deben expresarse en la misma unidad. Solo se leen las variables de la figura seleccionada: para un círculo no se piden base, altura ni lados.

## Datos de salida y constante

| Nombre | Tipo | ¿Qué representa? |
| --- | --- | --- |
| `area` | Real | Superficie de la figura. Se calcula y se muestra si las medidas son válidas. |
| `perimetro` | Real | Longitud del contorno. En el círculo se muestra con el nombre «Circunferencia». |
| Mensaje de rechazo | Texto | Indica que las medidas no son positivas o que la opción no existe. |
| `PI` | Constante | Valor aproximado de π, `3.141592653589793`, usado en las fórmulas del círculo. No es un dato de entrada ni una salida. |

`area` y `perimetro` **no se leen por teclado**. Cada caso les asigna sus resultados antes de mostrarlos. No son acumuladores y no necesitan inicializarse en cero. Si las longitudes están en centímetros, el perímetro queda en centímetros y el área en centímetros cuadrados.

## Análisis de resolución

### 1. Seleccionar la figura con `Segun`

Se muestra el menú y se lee `opcion`. `Segun opcion Hacer` ejecuta el caso que coincide con ese valor. Por ejemplo, `opcion = 2` solicita únicamente las medidas del rectángulo. Con `opcion = 9`, se ejecuta `De Otro Modo` y se informa que la opción no existe.

Esta estructura elige una alternativa; no repite el menú. Al terminar el caso seleccionado, finaliza el programa.

### 2. Validar con `Si / SiNo`

En cada caso se leen las medidas y después se evalúa una condición. Si es verdadera, se calculan y muestran los resultados. Si es falsa, el `SiNo` muestra un mensaje y no realiza el cálculo.

**Validar con `Si` no significa volver a pedir:** esta resolución rechaza el dato y termina. No contiene ciclos. Cero también se rechaza, porque se exige un valor estrictamente mayor que cero.

### 3. Cuadrado: una medida positiva

`Si lado > 0` comprueba la única medida necesaria. Con `lado = 4`, el área es `4² = 16` y el perímetro es `4*4 = 16`. Elevar al cuadrado multiplica el lado por sí mismo para obtener la superficie; multiplicar por cuatro suma los cuatro lados iguales del contorno.

Con `lado = 0` o `lado = -4`, se ejecuta el rechazo y no se asignan resultados.

### 4. Rectángulo: ¿por qué se utiliza `Y`?

`Si base > 0 Y altura > 0` exige que **ambas medidas sean positivas al mismo tiempo**. Basta que una falle para rechazar el cálculo. No sirve `O`, porque aceptaría, por ejemplo, una base positiva junto con una altura negativa.

| Base | Altura | `base > 0` | `altura > 0` | Resultado de `Y` |
| --- | --- | --- | --- | --- |
| `5` | `3` | Verdadero | Verdadero | Verdadero: se calcula. |
| `5` | `0` | Verdadero | Falso | Falso: se rechaza. |
| `-5` | `3` | Falso | Verdadero | Falso: se rechaza. |
| `-5` | `-3` | Falso | Falso | Falso: se rechaza. |

Con `base = 5` y `altura = 3`, `area = 5*3 = 15` y `perimetro = 2*(5+3) = 16`. Los paréntesis hacen que primero se sumen la base y la altura; luego se multiplica por dos porque hay dos lados de cada medida.

### 5. Triángulo: validar las cinco medidas

La condición une con `Y` las comprobaciones de `base`, `altura`, `lado1`, `lado2` y `lado3`. Todas deben ser mayores que cero. Por ejemplo, aunque base y altura sean válidas, `lado2 = 0` hace falsa toda la condición.

Se usan `base` y `altura` para `area <- (base*altura)/2`; se usan los tres lados para `perimetro <- lado1+lado2+lado3`. La altura es perpendicular a la base y no tiene por qué ser uno de los lados del triángulo.

Un ejemplo coherente es un triángulo rectángulo con `base = 3`, `altura = 4` y lados `3`, `4`, `5`: el área es `6` y el perímetro es `12`.

**Alcance de esta validación:** el algoritmo proporcionado comprueba positividad, pero no verifica que los lados formen un triángulo ni que base y altura correspondan a esos lados. Por ejemplo, los lados `1`, `2`, `10` son positivos pero no forman un triángulo. Se conserva tu resolución y se presupone que las medidas positivas describen la misma figura; una validación geométrica completa requeriría comprobaciones adicionales.

### 6. Círculo: validar el radio

`Si radio > 0` permite calcular `area <- PI*radio^2` y `perimetro <- 2*PI*radio`. Con `radio = 2`, el área es `4π` y la circunferencia también es `4π`, aproximadamente `12.57` cada una. Aunque coincida el número, representan superficie y longitud, respectivamente.

Con un radio cero o negativo se muestra el mensaje de rechazo. `PI` es constante: no cambia entre cálculos y no se solicita al usuario.

### 7. Resumen de las decisiones

| Caso | Condición para calcular | Resultado si no se cumple |
| --- | --- | --- |
| Cuadrado | `lado > 0` | Se rechaza el lado. |
| Rectángulo | Base y altura positivas. | Se rechazan las medidas. |
| Triángulo | Base, altura y tres lados positivos. | Se rechazan las medidas. |
| Círculo | `radio > 0` | Se rechaza el radio. |
| Opción fuera de `1` a `4` | No coincide con ningún caso. | `De Otro Modo` informa que no existe. |

### Equivalencias en C++

`Entero` se traduce como `int` y `Real` como `double`. `Si / SiNo` se expresa con `if / else`, `Y` con `&&`, y `Segun` con `switch`. Cada `case` termina con `break` para no continuar ejecutando los casos siguientes. `default` equivale a `De Otro Modo`.

En PSeInt, `lado^2` y `radio^2` elevan al cuadrado. En C++ se escriben `lado * lado` y `radio * radio`: `^` no es un operador de potencia. Se declara explícitamente `PI` con `const double`.

La versión C++ muestra dos decimales con `fixed` y `setprecision(2)`. Las validaciones de positividad conservan la lógica del pseudocódigo.
