## Ejercicio 1 · Sistema bancario de cuenta de ahorro

<Enunciado>
Una cooperativa financiera requiere desarrollar un sistema que permita
gestionar las operaciones básicas realizadas sobre una cuenta de ahorro.

Al iniciar el sistema, el cliente debe registrar el saldo actual disponible en
su cuenta. Posteriormente podrá seleccionar una operación:

1. **Consultar saldo disponible:** mostrar el monto actual de la cuenta.
2. **Realizar un depósito:** ingresar un monto y añadirlo al saldo disponible.
3. **Realizar un retiro:** solicitar un monto y verificar que exista saldo
   suficiente antes de descontarlo. Si el saldo es insuficiente, informar que
   la operación no puede realizarse.
4. **Calcular beneficio generado:** calcular el rendimiento obtenido durante
   una cantidad de meses, considerando una tasa anual del 5 %.

Si el usuario ingresa una opción diferente, se debe indicar que la operación no
existe.
</Enunciado>

### Fórmula del beneficio

El beneficio se calcula mediante la expresión:

<div class="my-5 border border-default bg-surface p-5 text-center font-mono text-sm sm:text-base">
  Beneficio = Saldo actual × 0.05 × (Meses / 12)
</div>

- **Saldo actual:** dinero disponible al momento del cálculo.
- **0.05:** tasa de rendimiento anual del 5 %.
- **Meses:** periodo durante el cual se desea calcular el beneficio.

### Consideraciones antes de programar

- El saldo inicial debe ser mayor que cero.
- Los montos de depósito y retiro deben ser mayores que cero.
- Un retiro solo puede realizarse si el monto solicitado no supera el saldo.
- La cantidad de meses debe ser mayor que cero.
- Cada alternativa del menú se resuelve en un caso de la estructura `Segun`.

### Ejemplos de funcionamiento

| Caso | Datos de entrada | Datos de salida / respuesta del programa |
| --- | --- | --- |
| Consultar | `saldo = 1500`, `opc = 1` | Saldo disponible: `Bs 1500`. |
| Depositar | `saldo = 1500`, `opc = 2`, `monto = 300` | Nuevo saldo: `Bs 1800`. |
| Retirar | `saldo = 1500`, `opc = 3`, `monto = 400` | Nuevo saldo: `Bs 1100`. |
| Retirar todo | `saldo = 1500`, `opc = 3`, `monto = 1500` | Nuevo saldo: `Bs 0`. |
| Saldo insuficiente | `saldo = 1500`, `opc = 3`, `monto = 1800` | Retiro rechazado. Se conserva el saldo: `Bs 1500`. |
| Beneficio | `saldo = 1500`, `opc = 4`, `meses = 6` | Beneficio generado: `Bs 37.50`. |
| Saldo inicial inválido | `saldo = 0` o `saldo = -50` | Se rechaza el inicio y no se muestra el menú. |
| Depósito inválido | `saldo = 1500`, `opc = 2`, `monto = 0` o negativo | No se puede realizar el depósito. |
| Retiro inválido | `saldo = 1500`, `opc = 3`, `monto = 0` o negativo | No se puede realizar el retiro. |
| Meses inválidos | `saldo = 1500`, `opc = 4`, `meses = 0` o negativo | No se puede calcular el beneficio. |
| Opción inexistente | `saldo = 1500`, `opc = 9` | La opción no existe. |

## Ejercicio 2 · Sistema de cálculo de figuras geométricas

<Enunciado>
Una empresa dedicada al diseño arquitectónico requiere un programa que permita
calcular medidas geométricas básicas utilizadas en sus proyectos.

El usuario podrá seleccionar el tipo de figura que desea analizar. Según la
figura seleccionada, el sistema deberá solicitar la información necesaria y
mostrar los resultados correspondientes.

Las figuras disponibles son:

1. **Cuadrado**
2. **Rectángulo**
3. **Triángulo**
4. **Círculo**

El programa debe permitir seleccionar una figura y realizar los cálculos
correspondientes. Si la opción ingresada no pertenece a las figuras disponibles,
deberá mostrar un mensaje indicando que la selección no es válida.
</Enunciado>

### Fórmulas

<div class="grid grid-cols-1 sm:grid-cols-2 gap-3 my-5">
  <div class="border border-default bg-surface p-4">
    <p class="font-mono text-xs uppercase tracking-widest text-brand">Opción 1</p>
    <h4 class="!mt-1 !mb-3">Cuadrado</h4>
    <div class="space-y-1 font-mono text-sm">
      <p>Área = lado²</p>
      <p>Perímetro = lado × 4</p>
    </div>
  </div>

  <div class="border border-default bg-surface p-4">
    <p class="font-mono text-xs uppercase tracking-widest text-brand">Opción 2</p>
    <h4 class="!mt-1 !mb-3">Rectángulo</h4>
    <div class="space-y-1 font-mono text-sm">
      <p>Área = base × altura</p>
      <p>Perímetro = 2 × (base + altura)</p>
    </div>
  </div>

  <div class="border border-default bg-surface p-4">
    <p class="font-mono text-xs uppercase tracking-widest text-brand">Opción 3</p>
    <h4 class="!mt-1 !mb-3">Triángulo</h4>
    <div class="space-y-1 font-mono text-sm">
      <p>Área = (base × altura) / 2</p>
      <p>Perímetro = lado 1 + lado 2 + lado 3</p>
    </div>
  </div>

  <div class="border border-default bg-surface p-4">
    <p class="font-mono text-xs uppercase tracking-widest text-brand">Opción 4</p>
    <h4 class="!mt-1 !mb-3">Círculo</h4>
    <div class="space-y-1 font-mono text-sm">
      <p>Área = π × radio²</p>
      <p>Circunferencia = 2 × π × radio</p>
    </div>
  </div>
</div>

### Ejemplos de funcionamiento

| Caso | Datos de entrada | Datos de salida / respuesta del programa |
| --- | --- | --- |
| Cuadrado | `opcion = 1`, `lado = 4` | Área: `16`. Perímetro: `16`. |
| Rectángulo | `opcion = 2`, `base = 5`, `altura = 3` | Área: `15`. Perímetro: `16`. |
| Triángulo | `opcion = 3`, `base = 3`, `altura = 4`, lados: `3`, `4`, `5` | Área: `6`. Perímetro: `12`. |
| Círculo | `opcion = 4`, `radio = 2` | Área: aproximadamente `12.57`. Circunferencia: aproximadamente `12.57`. |
| Lado inválido | `opcion = 1`, `lado = 0` o negativo | No se puede calcular. El lado debe ser positivo. |
| Altura inválida | `opcion = 2`, `base = 5`, `altura = 0` | No se puede calcular. Los valores deben ser positivos. |
| Lado del triángulo inválido | `opcion = 3`, `base = 3`, `altura = 4`, lados: `3`, `0`, `5` | No se puede calcular. Todos los valores deben ser positivos. |
| Radio inválido | `opcion = 4`, `radio = -2` | No se puede calcular. El radio debe ser positivo. |
| Opción inexistente | `opcion = 9` | La opción seleccionada no existe. |
