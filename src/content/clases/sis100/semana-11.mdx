## Ejercicio 1 · Multiplicación rusa

<Enunciado>
La **multiplicación rusa** es un método para calcular el producto de dos números mediante divisiones enteras entre `2`, duplicaciones y sumas de los valores correspondientes.

Realice un algoritmo **modular** que permita leer 2 enteros positivos en un módulo, y multiplicar los 2 enteros empleando el método de la **multiplicación rusa**.

Este método permite calcular el producto de **M × N** de la siguiente manera: en pasos sucesivos se divide `M` entre `2` (división entera) y se multiplica `N × 2`. Este proceso se repite hasta que `M` llega a **1**. Mostrar el resultado en el módulo principal.

Utilice únicamente **3 módulos para resolver el problema y un módulo adicional para el algoritmo principal**, haciendo un total de 4 módulos.
</Enunciado>

## Ejercicio 2 · Suma recursiva de una serie

<Enunciado>
Escriba un programa modular que solicite un número entero positivo `n` y muestre la suma de los primeros `n` términos de la siguiente serie:

`5/1 + 10/1 + 15/2 + 20/2 + 25/3 + 30/3 + ...`

El algoritmo debe desarrollarse utilizando únicamente **tres módulos recursivos**, sin contar el algoritmo principal, y **cuatro módulos en total**, contando el principal. Debe validar que `n` sea positivo, calcular la serie mediante recursividad y mostrar el resultado desde el algoritmo principal. No se permite utilizar ciclos repetitivos.
</Enunciado>
