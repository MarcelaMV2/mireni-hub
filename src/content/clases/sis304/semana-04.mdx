## Ejercicio 1

<Enunciado>
**1.- Dado el siguiente Modelo Lógico Global de Datos (MLGD)**

![Modelo Lógico Global de Datos](/material/sis304/semana1/ejercicio2.png)

**A.** Crear la base de datos **INVESTIGACION**.  
**B.** Crear las tablas y relaciones.

### Restricciones

- Fecha de inicio por defecto con la fecha del sistema.
- Presupuesto positivo y máximo de 7 dígitos.
- Un investigador no puede ser responsable de sí mismo.
- El motivo de revisión no puede ser nulo.
- Usar `AUTO_INCREMENT` para las claves numéricas generadas, cuando corresponda.
</Enunciado>

## Ejercicio 2

<Enunciado>
![Modelo Lógico Global de Datos](/material/sis304/semana1/ejercicio3.png)

**A.** Crear la base de datos **CONFERENCIAS**.  
**B.** Crear las tablas y relaciones.

### Restricciones

- Fechas por defecto con la fecha del sistema.
- La edad del conferencista debe estar en el rango de **21 a 80 años**.
- La categoría del conferencista solo puede ser: **N = Nacional, I = Internacional, E = Especial**.
- La modalidad de la conferencia solo puede ser: **P = Presencial, V = Virtual, H = Híbrida**.
- La capacidad de una conferencia debe estar entre **20 y 500 personas**.
- La duración de una conferencia debe estar entre **30 y 240 minutos**.
- El tipo de documento solo puede ser: **A = Artículo, L = Libro, P = Ponencia, T = Tesis**.
- La cantidad de páginas del documento debe estar entre **1 y 500**.
- El título del tema no puede ser nulo.
- El nombre de la conferencia no puede ser nulo.
- Usar `AUTO_INCREMENT` en identificadores numéricos generados.
</Enunciado>
