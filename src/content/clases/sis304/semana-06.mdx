## Procedimientos almacenados en MySQL

Un **procedimiento almacenado** es un conjunto de instrucciones SQL guardado con un nombre. Se crea con `CREATE PROCEDURE` y se ejecuta con `CALL`.

En esta clase trabajaremos con procedimientos que consultan la base `REPUESTOS`.

| Elemento                    | Función                                                                                       |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| `CREATE PROCEDURE nombre()` | Define y guarda el procedimiento.                                                             |
| `BEGIN ... END`             | Agrupa las instrucciones que se ejecutarán.                                                   |
| `DELIMITER`                 | Cambia temporalmente el separador para que MySQL no cierre el procedimiento en el primer `;`. |
| `CALL nombre()`             | Ejecuta el procedimiento almacenado.                                                          |
| `DROP PROCEDURE IF EXISTS`  | Elimina una versión anterior antes de volver a crearla.                                       |

## Ejercicio 1

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear un procedimiento llamado <code>EJ_SP1</code>, sin parámetros, que liste los repuestos comprados cuyo costo real esté entre <strong>150 y 250 Bs.</strong>, mostrando el repuesto, el proveedor y ese costo real.</p>

<Codigo archivo="ejercicio-1.sql" lang="sql" codigo={`USE REPUESTOS;
DELIMITER $$
CREATE PROCEDURE EJ_SP1()
BEGIN
	SELECT R.DESCRIPCION AS 'REPUESTO',
	       P.NOMBREP AS 'PROVEEDOR',
	       (C.COSTO - C.DESCUENTO + C.IMPUESTO) AS 'COSTO REAL Bs.'
	FROM REPUESTO R
		INNER JOIN COMPRA C ON R.CODIGO = C.CODIGO
		INNER JOIN PROVEEDOR P ON C.NIT = P.NIT
	WHERE (C.COSTO - C.DESCUENTO + C.IMPUESTO) BETWEEN 150 AND 250;
END $$
DELIMITER ;

CALL EJ_SP1();

SELECT * FROM COMPRA;`} />

## Ejercicio 2

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear un procedimiento llamado <code>EJ_SP2</code>, sin parámetros, que muestre la cantidad total entregada por cada encargado, de mayor a menor.</p>

<Codigo archivo="ejercicio-2.sql" lang="sql" codigo={`USE REPUESTOS;
DELIMITER $$
CREATE PROCEDURE EJ_SP2()
BEGIN
	SELECT E.NOMBRE AS 'ENCARGADO',
	       SUM(EN.CANTIDADE) AS 'TOTAL ENTREGADO'
	FROM ENCARGADO E
		INNER JOIN ENTREGA EN ON E.ITEM = EN.ITEM
	GROUP BY E.NOMBRE
	ORDER BY SUM(EN.CANTIDADE) DESC;
END $$
DELIMITER ;

CALL EJ_SP2();

SELECT * FROM ENTREGA;`} />

## Ejercicio 3

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear un procedimiento llamado <code>EJ_SP3</code>, sin parámetros, que liste los repuestos eléctricos con su potencia y el costo promedio de compra.</p>

<Codigo archivo="ejercicio-3.sql" lang="sql" codigo={`USE REPUESTOS;
DELIMITER $$
CREATE PROCEDURE EJ_SP3()
BEGIN
	SELECT R.DESCRIPCION AS 'REPUESTO ELECTRICO',
	       EL.POTENCIA AS 'POTENCIA (W)',
	       AVG(C.COSTO) AS 'COSTO PROMEDIO Bs.'
	FROM REPUESTO R
		INNER JOIN ELECTRICO EL ON R.CODIGO = EL.CODIGO
		INNER JOIN COMPRA C ON R.CODIGO = C.CODIGO
	GROUP BY R.DESCRIPCION, EL.POTENCIA
	HAVING COUNT(*) >= 1;
END $$
DELIMITER ;

CALL EJ_SP3();

SELECT * FROM ELECTRICO;`} />

## Ejercicio 4

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear un procedimiento llamado <code>EJ_SP4</code>, sin parámetros, que muestre los proveedores y repuestos cuya descripción termina en una vocal, con la cantidad total comprada.</p>

<Codigo archivo="ejercicio-4.sql" lang="sql" codigo={`USE REPUESTOS;
DELIMITER $$
CREATE PROCEDURE EJ_SP4()
BEGIN
	SELECT P.NOMBREP AS 'PROVEEDOR',
	       R.DESCRIPCION AS 'REPUESTO',
	       SUM(C.CANTIDAD) AS 'CANTIDAD TOTAL'
	FROM PROVEEDOR P
		INNER JOIN COMPRA C ON P.NIT = C.NIT
		INNER JOIN REPUESTO R ON C.CODIGO = R.CODIGO
	WHERE R.DESCRIPCION LIKE '%A'
	   OR R.DESCRIPCION LIKE '%E'
	   OR R.DESCRIPCION LIKE '%I'
	   OR R.DESCRIPCION LIKE '%O'
	   OR R.DESCRIPCION LIKE '%U'
	GROUP BY P.NOMBREP, R.DESCRIPCION
	ORDER BY P.NOMBREP ASC;
END $$
DELIMITER ;

CALL EJ_SP4();

SELECT * FROM REPUESTO;`} />

## Ejercicio 5

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear un procedimiento llamado <code>EJ_SP5</code>, sin parámetros, que muestre los repuestos y proveedores cuya cantidad total comprada supere el promedio general de <code>CANTIDAD</code>. Use variables locales.</p>

<Codigo archivo="ejercicio-5.sql" lang="sql" codigo={`USE REPUESTOS;
DELIMITER $$
CREATE PROCEDURE EJ_SP5()
BEGIN
	DECLARE CPRO FLOAT;

	SELECT AVG(CANTIDAD) INTO CPRO FROM COMPRA;

	SELECT R.DESCRIPCION AS 'REPUESTO',
	       P.NOMBREP AS 'PROVEEDOR',
	       SUM(C.CANTIDAD) AS 'CANTIDAD TOTAL'
	FROM REPUESTO R
		INNER JOIN COMPRA C ON R.CODIGO = C.CODIGO
		INNER JOIN PROVEEDOR P ON C.NIT = P.NIT
	GROUP BY R.DESCRIPCION, P.NOMBREP
	HAVING SUM(C.CANTIDAD) > CPRO;
END $$
DELIMITER ;

CALL EJ_SP5();

SELECT AVG(CANTIDAD) AS 'PROMEDIO GENERAL' FROM COMPRA;`} />

## Checklist de revisión

- El procedimiento tiene un nombre único y se elimina la versión anterior cuando corresponde.
- `DELIMITER` se cambia antes de `CREATE PROCEDURE` y se restaura después.
- Las instrucciones están dentro de `BEGIN ... END`.
- Las columnas no agregadas que aparecen en el `SELECT` están incluidas en `GROUP BY`.
- Las condiciones sobre `SUM`, `AVG` o `COUNT` se escriben en `HAVING`, no en `WHERE`.
- Cada procedimiento se prueba con `CALL nombre()` y se comprueba que sus tablas relacionadas tengan datos.
