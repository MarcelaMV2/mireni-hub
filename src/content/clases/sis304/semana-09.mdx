## ¿Qué es una función?

Una **función definida por el usuario** (`CREATE FUNCTION`) es un bloque de código SQL que siempre **devuelve un único valor** mediante la instrucción `RETURN`. A diferencia de un procedimiento almacenado, una función puede usarse directamente dentro de una consulta `SELECT`, una condición `WHERE` o una asignación `SET`, como si fuera una función nativa de MySQL.

Se declara con `CREATE FUNCTION`, el tipo de retorno se indica con `RETURNS`, y se acompaña de los atributos `READS SQL DATA` (solo lee datos) y `DETERMINISTIC` (con los mismos parámetros devuelve siempre el mismo resultado). El valor se entrega con `RETURN` y se recibe en una variable de sesión:

```sql
SET @resultado = nombre_funcion(valor1, valor2);
SELECT @resultado AS 'Etiqueta';
```

En los ejercicios de esta semana se usan funciones de agregado como `MAX`, `MIN`, `COUNT`, `SUM` y `AVG`, junto con `GROUP BY`, `ORDER BY ... DESC` y `LIMIT 1` para obtener un único resultado.

## Ejercicio 1

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear una función que reciba un valor mínimo de cantidad como parámetro y devuelva el costo más alto registrado en la tabla COMPRA entre los registros cuya cantidad supere ese valor.</p>

<Codigo archivo="ejercicio-1.sql" lang="sql" plegado codigo={`USE REPUESTOS;
DELIMITER $$
CREATE FUNCTION FUN1(CMIN INT) RETURNS FLOAT
READS SQL DATA DETERMINISTIC
BEGIN
    DECLARE COSTOMAX FLOAT;

    SELECT MAX(COSTO) INTO COSTOMAX
    FROM COMPRA
    WHERE CANTIDAD > CMIN;

    RETURN COSTOMAX;
END $$
DELIMITER ;

SET @CMAX = FUN1(16);
SELECT @CMAX AS 'COSTO MAXIMO';`} />

## Ejercicio 3

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear una función que reciba dos fechas (inicial y final) y devuelva el número total de unidades de repuestos entregadas entre esas fechas, consultando la tabla ENTREGA.</p>

<Codigo archivo="ejercicio-3.sql" lang="sql" plegado codigo={`USE REPUESTOS;
DELIMITER $$
CREATE FUNCTION FUN3(F1 DATE, F2 DATE) RETURNS INT
READS SQL DATA DETERMINISTIC
BEGIN
    DECLARE TOTAL INT;
    DECLARE AUX   DATE;

    IF (F1 > F2) THEN
        SET AUX = F1;
        SET F1  = F2;
        SET F2  = AUX;
    END IF;

    SELECT SUM(CANTIDADE) INTO TOTAL
    FROM ENTREGA
    WHERE DATE(FECHAE) BETWEEN F1 AND F2;

    RETURN TOTAL;
END $$
DELIMITER ;

SET @TOT = FUN3('2020-10-10', '2025-10-10');
SELECT @TOT AS 'CANTIDAD DE ENTREGA TOTAL';`} />

## Ejercicio 4

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear una función que reciba un año como parámetro y devuelva la descripción del repuesto con la mayor cantidad comprada durante ese año, consultando las tablas COMPRA y REPUESTO.</p>

<Codigo archivo="ejercicio-4.sql" lang="sql" plegado codigo={`USE REPUESTOS;
DELIMITER $$
CREATE FUNCTION FUN4(ANIO INT) RETURNS VARCHAR(50)
READS SQL DATA DETERMINISTIC
BEGIN
    DECLARE REP  VARCHAR(50);
    DECLARE CMAX INT;
    DECLARE COR  CHAR(6);

    SELECT CODIGO, MAX(CANTIDAD) INTO COR, CMAX
    FROM COMPRA
    WHERE YEAR(FECHA) = ANIO
    GROUP BY CODIGO
    ORDER BY MAX(CANTIDAD) DESC
    LIMIT 1;

    SELECT DESCRIPCION INTO REP
    FROM REPUESTO
    WHERE CODIGO = COR;

    RETURN REP;
END $$
DELIMITER ;

SET @REPU = FUN4(2025);
SELECT @REPU AS 'REPUESTO MAS COMPRADO';`} />

## Ejercicio 6

<p class="border-l-4 border-brand bg-surface px-4 py-3 leading-relaxed">Crear una función que reciba el mes y el año como parámetros y devuelva el nombre del proveedor que haya vendido la mayor cantidad de repuestos durante ese período, a partir de la tabla COMPRA.</p>

<Codigo archivo="ejercicio-6.sql" lang="sql" plegado codigo={`USE REPUESTOS;
DELIMITER $$
CREATE FUNCTION FUN6(MES INT, ANIO INT) RETURNS VARCHAR(50)
READS SQL DATA DETERMINISTIC
BEGIN
    DECLARE PROV VARCHAR(50);
    DECLARE NIP  CHAR(10);
    DECLARE CMAX INT;

    SELECT NIT, MAX(CANTIDAD) INTO NIP, CMAX
    FROM COMPRA
    WHERE MONTH(FECHA) = MES
      AND YEAR(FECHA)  = ANIO
    GROUP BY NIT
    ORDER BY CMAX DESC
    LIMIT 1;

    SELECT NOMBREP INTO PROV
    FROM PROVEEDOR
    WHERE NIT = NIP;

    RETURN PROV;
END $$
DELIMITER ;

SET @PROV = FUN6(9, 2025);
SELECT @PROV AS 'PROVEEDOR CON MAS VENTAS';`} />
